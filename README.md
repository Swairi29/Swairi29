# Hi there, I'm Swairi 👋

## Who am I 🙋‍♀️

I like understanding how things work from start to finish and to know where the data comes from, how it moves through a system, what happens when something breaks, and how it finally becomes useful to a real person.

Most of my work sits somewhere between machine learning, data engineering, backend systems and web development. I started out on the data side, but I keep drifting toward the parts that hold everything together: the pipelines, the APIs, and the applications built around a model.

I care more about things working well than looking impressive. A simple, reliable system is better than a clever one nobody can understand or maintain.

## What I'm focused on 🔭

- Web applications that actually solve problems
- RAG pipelines and agentic AI systems
- ML experimentation, and figuring out *why* a model behaves the way it does
- Data pipelines and warehousing
- Distributed systems patterns: messaging, sagas, and handling failure gracefully
- MLOps, or getting models out of notebooks and into something real
